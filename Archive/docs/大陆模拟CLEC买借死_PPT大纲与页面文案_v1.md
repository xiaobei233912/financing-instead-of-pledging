### 02｜CLEC 的买借死方法

**页面文案**

- **买：** 长期持有纳斯达克 100 指数基金。
- **借：** 通过 PAL 质押借出生活费，借款不用于再投资。
- **长期持有：** 目标是不靠卖出核心资产支付生活费，本息持续留在负债端。

底层设想：长期资产增长足以覆盖生活借款和利息累积，同时熬过深度下跌。

补充示例：信用卡用于支付，PAL 还账单，返现再投入股票。

**必要页注：** 本页按本项目对 CLEC 方法的整理。“永远不还”是策略目标，债务不会因此消失；实际 PAL 的付息与续借方式取决于合同。

**画面建议：** 长期持有资产、抵押借款、生活消费的关系示意，借款用途不连接证券再投资。

**来源：** [U]、[S5]。

### 04｜2000 年退休，能否坚持到今天

**页面文案**

本项目采用的 CLEC 核心检验：

**在 2000 年高点入场并退休，持续提取生活费，仍能存续。**

- QQQ 历史复权收盘最大回撤约 **83%**。
- 退休初期遇到大跌，生活费仍要支付，债务仍在增长。

**必要页注：** 约 83% 为本项目 QQQ 数据口径，低点在 2002 年，非“2000 单年跌幅”；通过此路径不等于覆盖所有未来风险。

### 05｜大陆股票质押为何难以直接照搬

**页面文案**

| 限制 | 对退休借款的影响 |
| --- | --- |
| 首笔通常至少 500 万元，后续每笔至少 50 万元 | 难匹配每年少量生活支出 |
| 资金应用于实体经济生产经营 | 与个人退休消费用途不匹配 |
| 初始质押标的范围受限 | 纳指 ETF 不能直接按普通两融担保品理解 |

首笔借 500 万元，若只占资产的 2%—3%，对应本金约 **1.67 亿—2.5 亿元**。

约定购回则是先向券商卖出证券、日后购回，购回期限不超过一年，也难匹配长期退休借款。

**必要页注：** 此处特指交易所股票质押式回购，非所有形式的证券质押贷款。门槛存在交易所认可的例外，约定购回延期后总期限一般不超过一年。

**画面建议：** 门槛、用途、标的的简洁比较，突出本金换算。

**来源：** [S1]、[S2]；本金数值由 500 万÷2%/3%计算。

### 06｜融资替代 PAL 的双账户思路

**页面文案**

**信用账户融资买入纳指，普通账户卖出等额自有纳指。**

| 信用账户 | 普通账户 |
| --- | --- |
| 接收自有担保品 | 保留可支配资产 |
| 融资买入纳指基金 | 卖出等额自有纳指基金 |
| 新增融资负债 | 取得可用于生活的现金 |

理想同步成交下，整体股票敞口基本不变，现金和负债同时增加。

**必要页注：** 融资款用于买入合格证券。组合操作是否符合账户合同，需按券商有效约定确认；本项目验证资金机制，尚无覆盖全流程的书面合规结论。

**画面建议：** 双账户操作示意，清楚标出融资买入、自有证券卖出与现金流向。

**来源：** [U]、[R1] 第 04、07 节、[S3]。

### 09｜140%与300%约束不同的事情

**页面文案**

**维持担保比例 = 信用账户资产市值 ÷（融资本金＋应计利息及费用）**

信用资产包括自有担保品和融资买入证券。普通账户资产不计入。

| 比例 | 本项目使用方式 |
| --- | --- |
| 150% / 140% / 130% | 用户提供的预警、警戒、平仓分档 |
| 140% | 回测的保守研究停止线 |
| 300% | 提取担保品后仍需满足的比例 |

**维持率足够高，仍可能因保证金余额或可转库存不足而无法融资生活。**

**必要页注：** 各券商最低维持要求以合同为准。300%针对担保品转出，不能当作所有新融资的统一准入线。

**画面建议：** 公式配两处标记，分别解释研究停止线和转出线。

**来源：** [U]、[R1] 第 03、18 节、[S3] 第 43—45 条。

### 10｜障碍一：再平衡可能触发还款

**页面文案**

- 普通账户资产足够时，可在普通账户完成整体调仓。
- 信用账户卖券可能触发偿债或扣息，改变“本息零偿还”。
- 卖股还款后再融资买现金产品，必须重新满足融资条件。

**还掉多少，不代表一定能再借回多少。**

示意：资产 1,100 万、债务 1,000 万，还清后只剩 100 万自有资产，新授信能力要重新计算。

**必要页注：** 该示意已低于本研究停止线，仅说明还款后重新融资的约束。偿还旧息后再借会增加新的计息本金，属于另列分支。

**画面建议：** 调仓前、偿债后、重新申请融资三个状态的简化对比。

**来源：** [U]、[R1] 第 05、06、18 节。

### 11｜障碍二：没有平仓，也可能没有生活费

**页面文案**

假设全部资产都在信用账户，维持率 **200%**。

- 高于研究停止线，尚未触发该项失败。
- 低于转出要求，担保品无法划回普通账户。
- 普通账户没有可支配资产，生活费无法取得。

**退休策略必须同时通过信用安全和生活现金流两项检验。**

**画面建议：** 信用账户标注“有资产、200%”，普通账户标注“无可支配现金”，突出中间的转出限制。

**来源：** [U]、[R1] 第 02、07 节。

### 12｜只维持最低担保，普通账户仍会耗尽

**页面文案**

最初尝试：每次只补足约 140%的信用担保，尽量留钱在普通账户。

用户原模拟的低谷示意：

| 项目 | 简化估算 |
| --- | ---: |
| 总资产 / 总债务 | 154% |
| 信用资产 / 总债务 | 140% |
| 留在普通账户的资产 | 总债务的 14% |

若总债务约 20 万，普通资产仅约 **2.8 万**；按年开销 2 万，只够 **1.4 年**。

资产开始反弹，也未必及时恢复到可转出的状态。

**必要页注：** 这是用户早期模拟的机制示意，非现金接力正式回测。20 万为简化总债务假设，精确值应含利息；普通资产能否立即变现另需检查。

**画面建议：** 展示 154%减去 140%后的可用资产缺口，不将此数标成正式双账户回测。

**来源：** [U]。

### 13｜现金接力：为无法借款的年份留预算

**页面文案**

**融资条件允许时借款生活，受限时由普通现金接力。**

- 普通账户预留多年生活储备。
- 融资与转出全部通过检查，才执行融资生活。
- 条件不满足，当年使用现金，下一年重新检查。
- 信用风险上升时，再按规则补充担保品。

**必要页注：** 主版本不主动还本付息，但部分年份会花自有现金，再平衡也可能卖股。

**画面建议：** 按年度展示两种生活费来源交替，突出“暂停后可以恢复”。

**来源：** [R1] 第 02—06 节。

### 15｜每年的生活费怎样支付

**页面文案**

1. **检查条件：** 操作后维持率至少 300%，保证金、自有可转证券、标的与授信均满足要求。
2. **全部满足：** 信用融资买入，等额自有证券划出并卖出，支付生活费。
3. **条件不足：** 当年停止新增生活借款，普通现金支付预算。
4. **支付之后：** 按规则再平衡，下一年重新检查。

普通现金无法付满当年预算，才记为**生活流动性失败**。

**必要页注：** 年初发起年度操作，包含证券到账及资金可取时间；融资被拒本身不等于生活费失败。

**画面建议：** 一条条件分支，末端汇合到生活费支付与再平衡。

**来源：** [R1] 第 04 节。

### 16｜再平衡：留住现金，允许配比暂时偏离

**页面文案**

| 情况 | 当前策略的动作 |
| --- | --- |
| 股票少于目标 | 只用普通现金超过初始底仓的部分补股 |
| 股票多于目标 | 在满足转出限制后，划出自有股票卖出补现金 |
| 普通现金不足底仓 | 停止买股，仍允许卖股补现金 |
| 受限而无法完全调仓 | 完成可执行部分，保留配比偏离 |

目标股票市值 = 当前总资产 × 目标股票比例。

**主版本通过有条件再平衡，避免为精确配比主动偿债。**

**画面建议：** 买股与卖股两列对照，特别突出“只限制买股”。

**来源：** [R1] 第 05 节。

### 17｜补担保：低于160%，争取补到200%

**页面文案**

**触发条件：信用维持率低于 160%。**

- 普通现金买入合格现金类证券，划入信用账户。
- 目标补到 200%，必要时可动用全部普通现金。
- 担保品到账后才计入信用资产。
- 以后满足转出条件，再按年度规则释放回普通账户。

补担保金额 = max（0，2 × 信用债务 − 信用资产）

**必要页注：** 补不满就按实际金额处理。低于 140%记研究失败；靠还本或卖券偿债才能存续时，须另列为改变零还款目标的应急分支。

**画面建议：** 160%、200%、140%三个水平标记，加一条到账时间说明。

**来源：** [R1] 第 06、17 节。

### 21｜与直接卖资产、PAL相比

**页面文案**

## 四、相对参考文稿的编辑处理

本节不上屏，说明为准确表达所作的调整。

1. **“永远不卖”与“每年再平衡”分开表达。** 正文使用“不靠卖出核心资产支付生活费”的目标，同时承认再平衡卖出。现金接力的本息零偿还不等于从不卖股或从不花自有现金。
2. **CLEC的3%与本研究的2%分开。** 第03页保留用户提供的70/30年借款3%介绍，所有正式现金接力结果统一按初始资产2%，不借此宣称3%通过回测。CLEC原方法中比例的基数和调整方式，待具体节目资料核验。
3. **质押门槛改为“首笔500万，后续50万”。** 不概括为每笔最低500万，也不将面向大股东的业务特征说成只有大股东有资格。初始质押和补充质押的证券范围不同，不能由基金可补充质押推导其可直接发起初始质押。
4. **不把账户操作推演写成已证实的全面合规。** 保留融资买入、普通卖出逻辑，注明有效合同条件和全流程确认状态，不添加无依据的违法判断。
5. **2.8%、单利长期挂息和140%展期作为项目输入。** 半年期可申请展期不等于无条件永久续贷。150%/140%/130%按用户提供的券商分档呈现，不表述为全国统一规定。
6. **保证金比例与折算率不能忽略。** 100%保证金仍影响可借额度，本稿采用正式模型的股票70%、现金类证券90%，不承诺具体基金永远按该值执行。集中度不展开计算，也不声称其规则永不变化。
7. **还款后复借不写成“一定借回”。** 参考文稿中的90万复借额取决于具体担保品及券商算法，正文保留100万剩余自有资产的例子，去掉固定90万结论。
8. **154%案例明确为用户早期示意。** 2.8万需以20万为总债务近似才能成立，若20万仅指本金，应另计利息。此案例不与正式现金接力逐日账混同。
9. **不采用“大陆无法配置任何杠杆基金”的泛化判断。** 按本项目资产范围不使用杠杆ETF，保留433介绍作为不展开的旁注。
10. **当前结果固定为阶段报告版本。** 采用比例再平衡、买股现金底线、160%/200%现金类证券补担保、140%停止线。早期智能再平衡、180%/220%救险及发生主动还款的结果不并入本稿。
